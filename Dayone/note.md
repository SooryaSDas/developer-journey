1. What is JavaScript?
JavaScript is a high-level, single-threaded programming language used to add interactivity and dynamic behavior to web applications. Today, it also runs on servers using Node.js.

2. V8 is Chrome engine? 
V8 is Google's JavaScript engine. It reads JavaScript code and compiles it into machine code so the CPU can execute it efficiently. Chrome and Node.js both use the V8 engine.
